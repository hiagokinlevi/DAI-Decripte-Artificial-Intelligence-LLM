## Website

Static HTML/CSS with a small optional citation-copy script. No external font, tracking pixel, analytics, cookie, paid dependency or server-side application is needed. Publish the root of `main` with GitHub Pages. Serve locally with `python3 -m http.server 8766`.

Run `python3 validate.py` to verify local links, manuscript checksums, structured metadata and citation links. English and Portuguese content is rendered without JavaScript. PDF typesetting is authoritative; extracted text may not preserve mathematical notation, tables or diagrams.
