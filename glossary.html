Twelve mechanisms, precisely named

Names bind to definitions and results in ADAI §7.2; DAI §2.5 maps them to the described system and observations. These are technical mechanisms, not a claim that the abbreviations are registered trademarks.

Technical glossary — ADAI §7.2 / DAI §2.5
AbbreviationMechanismMeaning
ACAutonomy CovenantThe conjunction of defended perimeter, bounded effect scope, declared rollback and capability-disjoint verification. All predicates must hold.
MEAModel-Excluded AuthorityThe admissibility function’s declared inputs exclude learned output. Retraining does not give the model execution authority.
ACOAction Contract ObjectA closed-catalogue action declared before execution, including effect scope and rollback.
EBTEvidence-Bound TargetingTargets come from a fixed key set in structured evidence; free text is outside the extraction domain. The paper distinguishes construction from receipt-verifiable provenance.
PPBPrincipal-Perimeter BindingThe execution perimeter is bound to the session’s principal, with no default perimeter.
DSCDiscriminator-Scoped ContainmentA separating predicate scopes containment to one principal at a shared enforcement point.
SAVSplit-Authority VerificationVerification uses a credential without write capability; separation is defined by capability rather than convention.
SSCSealed Session ChainOrdered session fields and predecessor digests form a hash-linked chain; a terminal digest is sealed under separate write authority.
PPRProofPath ReceiptA self-describing receipt carries the recomputation contract so an external verifier can check the chain without importing producer code.
ELRElement-Level ReconciliationReconciliation follows contained elements rather than provider rule identifiers, preserving meaning under aggregation.
RBTReview-Bound TestimonyHuman testimony enters as recorded evidence for deterministic review, not as a direct execution command.
SRLSealed Review LoopA scheduled review opens a new sealed session that references the original without reopening it.
